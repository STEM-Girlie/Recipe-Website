# 🍽️ **Recipe Website**

A simple, responsive recipe website that allows users to browse dishes, view ingredients, and follow cooking instructions. Built with clean HTML, CSS, and JavaScript, this project demonstrates core front‑end development skills including DOM manipulation, event handling, and UI design.

Live Demo: (https://stem-girlie.github.io/Recipe-Website/)  
Repository: [https://github.com/STEM-Girlie/Recipe-Website](https://github.com/STEM-Girlie/Recipe-Website)

## 🧁 **Overview**

### **Motivation**  
This project was created to practise front‑end development fundamentals and build a clean, user‑friendly interface for browsing recipes.

### **Objective**  
To create a simple recipe browsing experience using only vanilla JavaScript, HTML, and CSS — no frameworks.

### **Learning Outcomes**

- DOM manipulation  
- Event listeners and dynamic content  
- Responsive layout design  
- Clean project structuring  
- GitHub Pages deployment
- Working with API's

---

## 🍳 **Features**

- Search functionality
- Browse recipes with images and descriptions
- Favourite/unfavourite recipes    
- Responsive layout for mobile and desktop  
- Simple, clean UI  
- Lightweight and fast

## ⚙️ **Installation**

Clone the repository:

```bash
git clone https://github.com/STEM-Girlie/Recipe-Website.git
cd Recipe-Website
```

Open the project:

```bash
open index.html
```

Or simply double‑click **index.html**.

---

## 🍽️ **Usage**

1. Open the website in your browser  
2. Browse available recipes  
3. Click a recipe to view ingredients and instructions  
4. Enjoy cooking!
